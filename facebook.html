Website Facebook (Clone)

Front-End  |  2026

Deskripsi

Membuat website tiruan (clone) Facebook yang mensimulasikan alur obrolan sederhana. Aplikasi ini menampilkan sapaan pribadi dari mugbot, yaitu bot percakapan yang mengucapkan salam dan menanyakan nama pengguna, lalu menyediakan kolom isian beserta tombol kirim agar percakapan dapat berlangsung dua arah secara langsung di dalam browser. Proyek ini menjadi latihan saya dalam memisahkan struktur antarmuka, logika penanganan event, dan logika percakapan menggunakan JavaScript murni tanpa framework.

Fitur Utama

  • Sapaan otomatis dari mugbot yang menanyakan nama pengguna
  • Kolom input teks dan tombol kirim untuk mengirim pesan
  • Interaksi percakapan dua arah secara langsung di browser
  • Antarmuka minimalis dengan fokus pada area input
  • Dibangun tanpa framework, murni HTML, CSS, dan JavaScript
