Sistem Informasi Akademik (SIAKAD)

Web App  |  2026

Deskripsi

Mengembangkan Sistem Informasi Akademik (SIAKAD) untuk TK Al-Manaarussadiyyah, sebuah aplikasi web manajemen data sekolah yang saya rancang untuk memudahkan pengelola sekolah dalam mengelola data master secara terpusat. Aplikasi ini menyediakan dashboard analisis yang merangkum jumlah peserta didik, tenaga pendidik, dan rombongan belajar, sehingga administrator dapat memperoleh gambaran kondisi sekolah secara cepat tanpa perlu membuka satu per satu berkas.

Fitur Utama

  • Dashboard analisis berisi kartu ringkasan untuk siswa, guru, dan kelas
  • Manajemen data master (CRUD) untuk data guru, data siswa, dan data kelas
  • Menu pengumuman untuk menyebarkan informasi ke seluruh lingkungan sekolah
  • Navigasi berbasis sidebar yang memisahkan setiap modul aplikasi
  • Tampilan responsif sehingga tetap nyaman diakses melalui desktop maupun tablet

Teknologi

PHP MySQL Bootstrap 5

Tantangan

Membangun sistem informasi akademik dari nol untuk sekolah yang sebelumnya masih mengelola data secara manual. Tantangan utamanya adalah merancang database yang terstruktur agar data guru, siswa, dan kelas dapat terhubung dengan baik. Selain itu, memastikan tampilan dashboard mudah dipahami oleh administrator sekolah yang tidak memiliki latar belakang teknis.
